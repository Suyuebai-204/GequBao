# 歌曲宝 (GequBao)

一款基于 Electron + Vue 3 的桌面音乐播放器，支持在线搜索、热门推荐、排行榜、歌词浮层与本地音乐库。**本项目完全开源，仅供学习交流使用。**

说明：安装codeBuddy后，我进行了简单的逆向，使用AI快速的开发了这个桌面端程序，约5个小时，所以布局和很多逻辑没打磨。

---

## 功能特性

- **在线搜索**：歌曲搜索、搜索建议、猜你想找，多层解析兜底
- **发现与榜单**：热门推荐、周搜索榜、周下载榜，支持分页
- **播放与歌词**：流媒体播放、滚动歌词、播放地址失效自动重试
- **下载**：一键另存为，边下边显示进度
- **本地音乐**：选择文件夹扫描本机音频（mp3/flac/wav/m4a/aac/ogg/opus/ape），解析元数据与编码信息
- **最近播放**：本地持久化，自动记录收听历史

## 接口来源与数据说明

本项目**不托管、不存储任何音频文件**，所有在线内容均实时从公开第三方站点抓取：

| 数据 | 来源 |
| --- | --- |
| 搜索 / 热门 / 榜单 / 歌曲详情 / 播放直链 | [gequbao.com](https://www.gequbao.com) |
| 搜索热词 | [kuwo.cn](https://kuwo.cn) 开放接口 |

- 在线内容通过解析目标站点的 HTTP 接口与 HTML 页面获取，站点改版可能导致部分功能暂时失效，我们会尽量适配。
- 音频版权归原始权利方所有，请支持正版。若你是权利方并对内容有异议，请通过仓库 Issue 联系。

## 人机验证（验证码）

gequbao.com 的播放直链接口在检测到异常访问时会返回「请完成人机验证」。为保持顺畅播放，本软件内置自动处理：

- 使用 **tesseract.js** 离线 OCR 引擎，在本地识别站点返回的数字验证码（仅 0-9 白名单）；
- 自动取图 → 识别 → 携带凭证重试，最多 4 次；
- 识别训练数据首次运行会从官方 CDN 下载并缓存到系统临时目录；
- 若自动识别连续失败，会提示你在浏览器中打开对应歌曲页面手动播放，绝不弹窗打扰。

所有 OCR 与识别过程均在本地完成，不会上传你的任何数据。

## 本地音乐

- 通过自定义协议 `localmusic://` 播放本机文件，并对大文件（如 FLAC）支持 Range 拖动进度；
- 使用 **music-metadata** 读取标题、歌手、专辑、年份、码率/位深等元数据；
- 文件名形如「歌手 - 标题」时，即使元数据缺失也会自动兜底解析；
- 所选文件夹路径会记录到设置，下次启动自动扫描。

## 快速开始（开发 / 构建）

环境要求：Node.js 18+。

```bash
# 安装依赖
npm install

# 开发模式（热重载）
npm run dev

# 打包 Windows x64 安装包
npm run build:win
```

主要命令：

| 命令 | 说明 |
| --- | --- |
| `npm run dev` | 启动开发环境 |
| `npm run build` | 仅构建产物 |
| `npm run build:win` | 构建并打包 Windows 应用 |
